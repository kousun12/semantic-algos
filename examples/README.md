# Examples

These examples preserve complete Sem runs so you can inspect the request,
compiled program, execution trace, individual application boundaries, final
result, and any optional presentation artifacts as linked files.

- [KJV Essential Structure: Twelve Parables](kjv-essential-parables/) — a
  successful 39-application `sem-run` that decomposes the King James Bible into
  twelve structural leaves, forges the question at the heart of each leaf, and
  turns each question into a parable. It also preserves a rejected outline
  attempt and the optional `sem-present` view bundle.
